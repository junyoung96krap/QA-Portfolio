# QA Engineer Portfolio

안녕하세요. QA Engineer 박준영입니다.

약 5년간 자동차 전장 소프트웨어 QA 업무를 수행하며 요구사항 분석, 테스트 케이스 설계 및 수행, 결함 관리, 회귀 테스트 등 QA 전반의 경험을 쌓았습니다.
